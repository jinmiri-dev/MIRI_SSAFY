# 진미리 포트폴리오

삼성 청년 SW AI 아카데미 (Samsung SW AI Academy For Youth, SSAFY) 15기 부울경 캠퍼스 교육 이수 中

> SSAFY는 삼성전자가 운영하는 SW 인재 양성 교육 프로그램으로, 비전공자도 지원 가능하며 1년간 집중적인 SW 교육을 제공합니다.

---

## 교육 과정

| 기수 | 캠퍼스 | 기간 | 과정 | SW 역량 등급 |
|------|--------|------|------|------------|
| SSAFY 15기 | 부울경 | 2026 | Python · Web · AI · Django · DB · JavaScript · Vue.js | IM |

> **SW 역량 등급**이란 SSAFY에서 실시하는 코딩 역량 평가로, A+·A·B+·B·IM·D 등급으로 나뉩니다. IM(Intermediate Middle)은 중급 수준으로, 기본적인 알고리즘 문제를 해결할 수 있는 역량을 의미합니다.
