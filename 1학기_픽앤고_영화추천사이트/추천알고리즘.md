# Pick & Go 영화 추천 시스템 설명 문서

## 0. 전체 추천 시스템 개요

Pick & Go의 추천 시스템은 사용자의 상황과 보유 데이터에 따라 서로 다른 방식으로 동작한다.

크게 다음 4가지 추천 기능으로 구성된다.

| 기능         | 추천 기준                           | 개인화 요소        | AI 사용 여부         |
| ---------- | ------------------------------- | ------------- | ---------------- |
| 오늘의 추천     | 감정, 명대사, 직접 입력 문장, MVTI, 평점/인기도 | 현재 감정 + MVTI  | 사용               |
| 픽시에게 요청하기  | 사용자의 자연어 메시지                    | 감정/장르/연대 키워드  | 사용               |
| MVTI 맞춤 추천 | MVTI 성향, 장르, 평점, 인기도, AI 매칭 점수  | MVTI          | 일부 사용            |
| TOP10      | MVTI, 평점, 인기도, 투표 수             | MVTI가 있으면 개인화 | DB에 저장된 AI 점수 사용 |
| 친구 궁합      | MVTI 유사도, 선호 장르, 찜/리뷰 취향        | 나와 친구의 데이터    | 직접 호출 없음         |

핵심 설계 방향은 다음과 같다.

> 사용자의 MVTI 데이터가 있으면 성향 기반 개인화 추천을 제공하고,
> MVTI 데이터가 없더라도 감정, 장르, 평점, 인기도, 찜/리뷰 데이터를 활용해 추천이 끊기지 않도록 설계했다.

---

# 1. 오늘의 추천

## 1-1. 오늘의 추천 기능 흐름

오늘의 추천은 사용자가 선택한 감정, 직접 입력한 문장, 선택한 명대사, 명대사가 나온 영화, MVTI 정보를 종합해 추천 결과를 만든다.

전체 과정은 다음과 같다.

```text
1. 사용자가 오늘의 기분을 선택하거나 직접 문장을 입력한다.
2. 감정 키워드를 분석해 관련 장르로 변환한다.
3. 명대사를 선택했다면, 해당 명대사가 나온 영화와 장르를 찾는다.
4. 감정 장르 + 명대사 영화 장르를 기준으로 후보 영화를 만든다.
5. 후보 영화에는 평점, 인기도, 투표 수, 장르, 줄거리, MVTI 매칭 정보가 포함된다.
6. 후보 목록을 AI에게 전달한다.
7. AI가 후보 중 오늘의 감정과 가장 잘 맞는 영화를 선택한다.
8. 추천 결과는 match_percent 기준으로 정렬되어 화면에 출력된다.
```

---

## 1-2. 감정 키워드와 장르 매핑

사용자가 입력한 감정이나 문장에 따라 관련 장르가 자동으로 매핑된다.

| 감정/키워드             | 연결 장르          |
| ------------------ | -------------- |
| 행복, 기쁜, 웃고, 웃긴     | 코미디, 가족        |
| 신나, 재밌             | 코미디, 액션        |
| 의미, 인생             | 드라마, 역사        |
| 잔잔, 편안, 따뜻         | 드라마, 로맨스, 가족   |
| 힐링                 | 애니메이션, 가족, 코미디 |
| 위로, 회복             | 드라마, 가족        |
| 슬프, 슬퍼, 우울, 눈물, 울고 | 드라마, 로맨스       |
| 사랑, 설렘, 이별         | 로맨스, 드라마, 코미디  |
| 놀란, 반전             | 미스터리, 스릴러      |
| 무서워                | 공포, 스릴러        |
| 긴장                 | 스릴러, 액션        |

예를 들어 사용자가 다음과 같이 입력하면,

```text
행복한 날이었는데 갑자기 슬퍼졌어
```

문장 안의 `슬퍼졌` 키워드가 감지되어 드라마, 로맨스 계열 영화가 우선 후보로 잡힌다.

---

## 1-3. 후보 영화 선정 기준

오늘의 추천에서는 먼저 영화 후보군을 만든다.

```text
기본 조건:
- vote_count 100 이상
- 감정 장르 또는 명대사 영화 장르와 겹치는 영화 우선
- 평점 높은 순으로 최대 80개 후보 선정
```

후보가 너무 적으면 다음 방식으로 보완한다.

```text
보완 조건:
- vote_count 100 이상
- 이전에 추천한 영화 제외
- 평점 높은 영화 추가
- 최대 50개 추가 후보 사용
```

즉 오늘의 추천은 처음부터 전체 영화를 무작위로 AI에게 넘기는 것이 아니라,
감정과 장르 기준으로 1차 필터링한 뒤 AI가 최종 선택하는 구조다.

---

## 1-4. PICK GO 종합 추천 점수

오늘의 추천에서 AI에게 전달되는 PickGo 종합 추천 기준은 다음과 같다.

| 항목         |   배점 | 설명                                            |
| ---------- | ---: | --------------------------------------------- |
| 오늘 감정 궁합   |  60점 | 사용자의 감정, 직접 입력 분위기, 명대사와 영화 분위기가 얼마나 잘 맞는지    |
| MVTI 취향 매칭 |  30점 | 사용자의 MVTI와 영화 장르, 서사, 분위기, 인물 성향이 얼마나 맞는지     |
| 평점/대중성     |  10점 | TMDB 평점, 투표 수, 인기도를 보조 지표로 반영                 |
| 총점         | 100점 | emotion_score + mvti_score + popularity_score |

계산 구조는 다음과 같다.

```text
match_percent = emotion_score + mvti_score + popularity_score

emotion_score: 0~60점
mvti_score: 0~30점
popularity_score: 0~10점
```

---

## 1-5. 실제 AI 프롬프트 핵심 구조

오늘의 추천에서 AI에게 전달되는 프롬프트의 핵심은 다음과 같다.

```text
너는 PickGo의 영화 추천 AI 큐레이터야.

사용자가 선택한 감정, 명대사, 직접 입력한 분위기, MVTI 성향을 바탕으로
후보 영화 중 가장 잘 맞는 영화를 추천해야 해.

PickGo 종합 추천 점수 기준은 다음과 같아.

1. 오늘 감정 궁합 60점
- 사용자가 선택한 감정, 직접 입력한 분위기, 선택한 명대사와
  영화의 줄거리/분위기가 얼마나 잘 맞는지 평가해.
- 감정이 슬픔이면 단순히 우울한 영화만 고르지 말고,
  위로, 회복, 공감, 새로운 시작의 흐름이 있는 영화를 높게 평가해.

2. MVTI 취향 매칭 30점
- 사용자의 MVTI 유형과 영화의 장르, 서사, 분위기, 인물 성향이
  얼마나 잘 맞는지 평가해.
- MVTI와 맞지 않는 영화는 최종 점수를 과하게 높이지 마.

3. 평점/대중성 10점
- TMDB 평점, 투표 수, 인기도를 보조 지표로 반영해.
- 평점이 높고 투표 수가 많은 영화는 신뢰도가 높다고 판단해.

반드시 지켜야 할 조건:
- 추천 영화는 후보 영화 목록 안에서만 골라.
- 이전에 추천한 영화 ID 목록은 절대 다시 추천하지 마.
- match_percent는 emotion_score + mvti_score + popularity_score를 합산한 값이야.
- emotion_score는 0~60, mvti_score는 0~30, popularity_score는 0~10 사이 정수로 줘.
- 가능하면 match_percent 80 이상인 영화만 골라.
- JSON 형식으로만 응답해.
```

AI 응답 형식은 다음 JSON 구조로 제한한다.

```json
{
  "vibe": "감정 키워드 또는 현재 감정을 표현한 한 문장",
  "reason": "추천 방향 한 문장",
  "main_comment": "명대사 영화가 왜 오늘 감정과 어울리는지 1~2문장",
  "picks": [
    {
      "id": 123,
      "emotion_score": 55,
      "mvti_score": 25,
      "popularity_score": 8,
      "match_percent": 88,
      "comment": "왜 이 감정, 명대사, MVTI 성향에 어울리는지 1~2문장"
    }
  ]
}
```

이렇게 JSON으로만 받기 때문에 프론트에서 안정적으로 추천 카드에 표시할 수 있다.

## 1-6. MVTI 검사를 하지 않은 사용자의 오늘의 추천

회원가입은 했지만 MVTI 검사를 하지 않은 사용자는 `mvti_type`이 없기 때문에 MVTI 기반 개인화 점수는 정확히 계산되지 않는다.

이 경우 추천 기준은 다음과 같다.

| 사용 데이터     | 반영 여부         |
| ---------- | ------------- |
| 오늘의 감정     | 반영            |
| 직접 입력 문장   | 반영            |
| 선택한 명대사    | 반영            |
| 명대사 영화의 장르 | 반영            |
| 영화 평점      | 반영            |
| 영화 인기도     | 반영            |
| 투표 수       | 반영            |
| MVTI 성향    | 미반영 또는 중립값 처리 |

MVTI가 없을 경우 기본적으로 MVTI 매칭은 중립값에 가깝게 처리된다.

```text
mvti_match = 50
mvti_score = min(30, round(mvti_match * 0.3))
```

즉 MVTI 검사를 하지 않은 사용자에게도 추천이 제공되며, 이때는 성향보다 감정과 영화 자체의 데이터가 더 중요하게 작동한다.

발표 설명 예시:

> MVTI 검사를 하지 않은 사용자는 성향 기반 점수를 정확히 계산할 수 없기 때문에, 오늘의 감정과 직접 입력한 문장, 명대사, 장르, 평점, 인기도 중심으로 추천합니다. MVTI 항목은 중립값으로 처리해 추천 기능이 끊기지 않도록 했습니다.

# 2. 픽시에게 요청하기

## 2-1. 기능 개요

픽시에게 요청하기는 사용자가 자유롭게 문장을 입력하면, 그 문장에서 감정/장르/상황 키워드를 찾아 영화 추천으로 연결하는 기능이다.

예를 들어 사용자가 다음과 같이 말할 수 있다.

```text
나 아까는 행복했는데 갑자기 슬퍼졌어.
위로되는 영화 추천해줘.
```

이 경우 픽시는 문장에서 `슬퍼`, `위로`와 같은 키워드를 찾고 드라마, 로맨스, 가족 계열 후보 영화를 우선 추천한다.

---

## 2-2. 추천 과정

```text
1. 사용자가 픽시에게 자유 문장을 입력한다.
2. 메시지에서 감정, 장르, 연대 키워드를 찾는다.
3. 키워드에 맞는 후보 영화를 DB에서 가져온다.
4. 후보 영화 목록을 AI에게 전달한다.
5. AI는 후보 영화 중 사용자 문장과 가장 잘 맞는 영화를 고른다.
6. AI 답변은 짧고 따뜻한 말투로 생성된다.
7. 영화 제목은 카드로 따로 보여준다.
```

---

## 2-3. 픽시 프롬프트 핵심 구조

픽시 기능에서 사용한 AI 프롬프트의 핵심은 다음과 같다.

```text
사용자가 영화와 무관한 일상 질문을 하면,
진짜 도움이 되는 답변을 먼저 해주고 영화로 자연스럽게 연결해.

예시:
- '점심 뭐 먹지'
  → '오늘은 얼큰한 짬뽕 어때요? 짬뽕 먹으면서 이런 영화 보면 스트레스가 확 풀릴 거예요!'

- '심심해'
  → '심심할 땐 픽키한테 왔죠! 두근두근 설레는 영화로 기분 바꿔볼까요?'

답변은 2~3줄:
1줄: 질문에 진짜로 답변
2줄: 영화로 자연스럽게 연결

영화 제목은 답변 텍스트에 절대 언급 금지.
카드로 따로 보여줄 거야.

단, 추천 후보 중 가장 잘 맞는 영화 제목은 반드시 「제목」 형식으로 내부에 포함시켜.
각 추천 영화마다 추천 이유를 한 줄로 붙여줘.

규칙:
- 한국어로 답변
- 150자 이내
- 픽키답게 귀엽고 따뜻하게
- 추천 후보 안에서만 골라야 함
```

이 구조 덕분에 사용자는 챗봇과 대화하는 느낌을 받지만, 실제 추천 영화는 DB 후보 안에서 안정적으로 선택된다.

# 3. MVTI 맞춤 추천

## 3-1. 기능 개요

MVTI 맞춤 추천은 사용자의 MVTI 유형을 영화 장르 취향으로 변환하고,
영화의 장르, 평점, 인기도, 투표 수, AI 매칭 점수를 함께 사용해 추천한다.

MVTI 유형별로 선호 장르가 다르게 설정되어 있다.

예시:

| MVTI | 선호 장르 예시           |
| ---- | ------------------ |
| INTJ | 드라마, 미스터리, SF, 스릴러 |
| ENTJ | 액션, 모험, 드라마, 스릴러   |
| INFP | 로맨스, 판타지, 드라마, 음악  |
| ENFP | 코미디, 모험, 판타지, 로맨스  |
| ISTP | 액션, 범죄, SF, 스릴러    |
| ESFP | 코미디, 음악, 로맨스, 모험   |

---

## 3-2. MVTI 글자별 장르 가중치

MVTI는 단순히 16개 유형만 보는 것이 아니라, 각 글자별 성향도 장르 가중치로 반영한다.

| 글자 | 성향 | 선호 장르 예시                 |
| -- | -- | ------------------------ |
| E  | 외향 | 코미디, 모험, 음악, 가족, 액션      |
| I  | 내향 | 드라마, 미스터리, SF, 역사, 다큐멘터리 |
| N  | 직관 | SF, 판타지, 미스터리, 애니메이션, 모험 |
| S  | 감각 | 액션, 범죄, 역사, 스릴러, 전쟁      |
| T  | 사고 | 스릴러, 범죄, 액션, SF, 미스터리    |
| F  | 감정 | 로맨스, 드라마, 가족, 음악, 애니메이션  |
| J  | 판단 | 역사, 범죄, 드라마, 스릴러, 전쟁     |
| P  | 인식 | 코미디, 모험, 판타지, 음악, 애니메이션  |

예를 들어 ENTJ라면 다음 성향이 반영된다.

```text
E: 코미디, 모험, 음악, 가족, 액션
N: SF, 판타지, 미스터리, 애니메이션, 모험
T: 스릴러, 범죄, 액션, SF, 미스터리
J: 역사, 범죄, 드라마, 스릴러, 전쟁
```

이 장르들과 영화의 장르가 겹칠수록 규칙 기반 점수가 높아진다.

---

## 3-3. MVTI 궁합 점수 계산 방식

MVTI 맞춤 추천의 궁합률은 다음 두 점수를 합산해 만든다.

```text
궁합률 = 규칙 기반 점수 + AI 매칭 점수
```

단, 최종 궁합률은 너무 낮거나 너무 높게 보이지 않도록 범위를 제한한다.

```text
match_percent = max(35, min(total_score, 98))
```

즉 최종 궁합률은 최소 35%, 최대 98% 사이로 표시된다.

---

## 3-4. 규칙 기반 점수 계산

규칙 기반 점수는 최대 약 70점 규모로 계산된다.

| 항목            | 최대 점수 | 설명                            |
| ------------- | ----: | ----------------------------- |
| MVTI 장르 일치 점수 |   40점 | MVTI 글자별 선호 장르와 영화 장르가 겹치는 정도 |
| 평점 점수         |   15점 | TMDB 평점 기준                    |
| 인기도 점수        |    8점 | TMDB popularity 기준            |
| 투표 수 점수       |    5점 | vote_count 기준                 |
| 장르 다양성 점수     |    2점 | 영화가 가진 장르 개수                  |
| 합계            | 약 70점 | 규칙 기반 추천 점수                   |

계산식은 다음과 같다.

```text
rule_score =
genre_score
+ rating_score
+ popularity_score
+ vote_count_score
+ diversity_score
```

세부 계산은 다음과 같다.

```text
rating_score = min((vote_average / 10) * 15, 15)

popularity_score = min((popularity / 300) * 8, 8)

vote_count_score = min((vote_count / 2000) * 5, 5)

diversity_score = min(genre_count * 0.7, 2)
```

---

## 3-5. AI 매칭 점수

AI 매칭 점수는 `MovieAiMatch` 테이블에 저장된 값을 사용한다.

| 데이터         | 설명                               |
| ----------- | -------------------------------- |
| ai_score    | 해당 MVTI와 영화가 얼마나 잘 맞는지에 대한 AI 점수 |
| ai_reason   | 왜 이 MVTI에게 어울리는지에 대한 설명          |
| ai_keywords | 추천 키워드                           |

최종 궁합률 계산에서는 다음과 같이 사용된다.

```text
total_score = rule_score + ai_score
match_percent = round(max(35, min(total_score, 98)))
```

즉 MVTI 맞춤 추천은 단순 장르 추천이 아니라,

```text
MVTI 장르 매칭
+ 영화 평점
+ 인기도
+ 투표 수
+ AI가 분석한 성향 적합도
```

를 모두 반영한다.

---

## 3-6. 궁합순, 평점순, 인기순 차이

MVTI 맞춤 추천 화면에는 정렬 기준이 3가지 있다.

| 정렬  | 기준                           | 점수 범위      |
| --- | ---------------------------- | ---------- |
| 궁합순 | Pick & Go가 계산한 match_percent | 35~98%     |
| 평점순 | TMDB vote_average            | 보통 0~10점   |
| 인기순 | TMDB popularity              | TMDB 원본 수치 |

중요한 점은 세 기준이 모두 100점 만점이 아니라는 것이다.

예를 들어 맨 왼쪽 영화인데 궁합률이 56%일 수 있다.
그 이유는 사용자가 `평점순`이나 `인기순`으로 보고 있을 경우, 궁합률이 가장 높은 영화가 아니라 평점이나 인기도가 높은 영화가 먼저 나올 수 있기 때문이다.

발표 설명 예시:

> 궁합, 평점, 인기는 같은 기준의 100점 만점 점수가 아닙니다. 궁합은 Pick & Go가 계산한 35~98% 범위의 개인화 점수이고, 평점은 TMDB의 10점 만점 평점, 인기는 TMDB의 popularity 지표입니다. 그래서 평점순이나 인기순에서는 궁합률이 낮은 영화가 앞에 올 수 있습니다.

---

## 3-7. MVTI 검사를 하지 않은 사용자의 MVTI 맞춤 추천

MVTI 검사를 하지 않은 사용자는 MVTI 성향 정보가 없기 때문에 개인화 궁합률을 계산할 수 없다.

이 경우에는 다음 기준으로 기본 추천을 제공한다.

```text
전체 영화 중 평점이 높은 영화 50개
```

즉 MVTI가 없는 사용자는 다음 정보를 제공받는다.

| 항목         | 제공 여부         |
| ---------- | ------------- |
| 영화 제목      | 제공            |
| 포스터        | 제공            |
| 평점         | 제공            |
| 장르         | 제공            |
| 줄거리        | 제공            |
| MVTI 궁합률   | 제공하지 않거나 null |
| MVTI 추천 이유 | 제공하지 않음       |

발표 설명 예시:

> MVTI 검사를 하지 않은 사용자는 성향 정보가 없기 때문에 MVTI 궁합률은 계산하지 않습니다. 대신 전체 영화 중 평점이 높은 영화를 기본 추천으로 보여주어 사용자가 서비스를 계속 이용할 수 있도록 했습니다.

---

# 4. TOP10 추천

## 4-1. TOP10 기능 개요

TOP10은 Pick & Go의 대표 추천 영화 10개를 보여주는 기능이다.

MVTI가 있는 사용자와 없는 사용자의 기준이 다르다.

| 사용자 상태          | TOP10 기준                                    |
| --------------- | ------------------------------------------- |
| 비로그인 또는 MVTI 없음 | 인기도, 평점, 투표 수 기반                            |
| 로그인 + MVTI 있음   | MVTI 궁합률, AI 점수, 규칙 기반 점수, 평점, 인기도, 투표 수 기반 |

---

## 4-2. MVTI가 없는 사용자의 TOP10

MVTI가 없는 사용자는 개인화 추천이 어렵기 때문에, 전체 영화 중 대중적으로 검증된 영화를 기준으로 TOP10을 선정한다.

후보 조건은 다음과 같다.

```text
- vote_count 50 이상
- 인기도 높은 순 + 평점 높은 순
- 최대 300개 후보
```

Pick Score 계산식은 다음과 같다.

```text
pick_score =
popularity * 0.35
+ vote_average * 7
+ min(vote_count / 300, 15)
```

각 항목의 의미는 다음과 같다.

| 항목                        | 의미          |
| ------------------------- | ----------- |
| popularity * 0.35         | 현재 대중적 관심도  |
| vote_average * 7          | 영화 평점       |
| min(vote_count / 300, 15) | 투표 수 기반 신뢰도 |

즉 MVTI가 없는 사용자의 TOP10은 다음 기준으로 선정된다.

```text
대중성 + 평점 + 투표 수 신뢰도
```

태그는 다음과 같이 붙는다.

| 조건                  | 태그       |
| ------------------- | -------- |
| popularity >= 300   | 지금 뜨는    |
| vote_average >= 8.0 | 평점 주목    |
| 그 외                 | 오늘의 Pick |

발표 설명 예시:

> MVTI가 없는 사용자의 TOP10은 개인화 정보가 없기 때문에 전체 영화 중 인기도, 평점, 투표 수를 반영해 대중적으로 검증된 영화를 보여줍니다.

---

## 4-3. MVTI가 있는 사용자의 TOP10

MVTI가 있는 사용자는 개인화 Pick Score를 계산한다.

후보 영화는 다음 방식으로 구성된다.

```text
1. 사용자의 MVTI 선호 장르에 해당하는 영화 후보를 가져온다.
2. vote_count 20 이상인 영화만 사용한다.
3. 인기도와 평점이 높은 순으로 최대 250개를 가져온다.
4. 다양성을 위해 전체 인기 영화 후보 120개를 추가한다.
5. 같은 영화가 중복 노출되지 않도록 id와 title 기준으로 중복 제거한다.
```

개인화 Pick Score 계산식은 다음과 같다.

```text
pick_score =
match_percent * 0.62
+ ai_score * 0.9
+ rule_score * 0.35
+ vote_average * 2.2
+ min(popularity / 20, 8)
+ min(vote_count / 1000, 5)
```

각 항목의 의미는 다음과 같다.

| 항목                        | 설명                         |
| ------------------------- | -------------------------- |
| match_percent * 0.62      | 사용자의 MVTI와 영화의 최종 궁합률      |
| ai_score * 0.9            | AI가 분석한 MVTI 적합도           |
| rule_score * 0.35         | 장르, 평점, 인기도, 투표 수 기반 규칙 점수 |
| vote_average * 2.2        | TMDB 평점                    |
| min(popularity / 20, 8)   | 인기도 보정                     |
| min(vote_count / 1000, 5) | 투표 수 신뢰도 보정                |

즉 MVTI가 있는 사용자의 TOP10은 다음 기준을 모두 반영한다.

```text
MVTI 궁합률
+ AI 매칭 점수
+ 규칙 기반 점수
+ 평점
+ 인기도
+ 투표 수
```

태그는 다음 기준으로 표시된다.

| 조건                  | 태그      |
| ------------------- | ------- |
| match_percent >= 85 | MVTI 찰떡 |
| match_percent >= 80 | MVTI 강추 |
| match_percent >= 70 | 취향 저격   |
| 그 외                 | 추천 후보   |

발표 설명 예시:

> MVTI TOP10은 단순히 평점이 높은 영화가 아니라, 사용자의 MVTI 성향과 영화의 장르·분위기가 얼마나 잘 맞는지, AI 매칭 점수, 규칙 기반 점수, 평점, 인기도, 투표 수를 종합해 선정합니다.

---

# 5. 친구 궁합

## 5-1. 친구 궁합 기능 개요

친구 궁합은 나와 친구의 영화 취향이 얼마나 비슷한지를 계산하는 기능이다.

궁합률은 다음 3가지 기준을 합산한다.

```text
친구 궁합률 =
MVTI 글자 유사도
+ MVTI 선호 장르 유사도
+ 찜/리뷰 기반 실제 취향 유사도
```

총점은 최대 100점이다.

---

## 5-2. 친구 궁합 점수 계산

| 항목             | 최대 점수 | 설명                            |
| -------------- | ----: | ----------------------------- |
| MVTI 글자 유사도    |   40점 | MVTI 4글자가 얼마나 일치하는지           |
| MVTI 선호 장르 유사도 |   35점 | 두 사람의 MVTI 선호 장르가 얼마나 겹치는지    |
| 찜/리뷰 실제 취향 유사도 |   25점 | 찜한 영화와 리뷰 작성 영화의 장르가 얼마나 겹치는지 |
| 합계             |  100점 | 최종 친구 궁합률                     |

---

## 5-3. MVTI 글자 유사도

MVTI 글자 유사도는 최대 40점이다.

각 글자별 가중치는 다음과 같다.

| 위치     | 예시  |  점수 |
| ------ | --- | --: |
| 1번째 글자 | E/I | 12점 |
| 2번째 글자 | N/S | 10점 |
| 3번째 글자 | T/F | 10점 |
| 4번째 글자 | J/P |  8점 |

예를 들어 나의 MVTI가 `ENTJ`, 친구의 MVTI가 `ENFP`라면 다음과 같이 계산된다.

```text
E 일치: +12점
N 일치: +10점
T/F 불일치: +0점
J/P 불일치: +0점

MVTI 글자 유사도 = 22점
```

만약 둘 중 한 명이라도 MVTI가 없다면 기본 점수 20점을 부여한다.

```text
if not my_mvti or not target_mvti:
    return 20
```

---

## 5-4. MVTI 선호 장르 유사도

MVTI 선호 장르 유사도는 최대 35점이다.

계산 방식은 자카드 유사도 방식이다.

```text
genre_score =
공통 선호 장르 수 / 전체 선호 장르 수 * 35
```

예를 들어,

```text
나의 선호 장르: 액션, 모험, 스릴러, 드라마
친구의 선호 장르: 드라마, 로맨스, 코미디, 가족
공통 장르: 드라마
전체 장르: 액션, 모험, 스릴러, 드라마, 로맨스, 코미디, 가족
```

이면,

```text
genre_score = 1 / 7 * 35 = 5점
```

둘 중 한 명의 MVTI 선호 장르가 없으면 기본 점수 15점을 부여한다.

---

## 5-5. 찜/리뷰 기반 실제 취향 유사도

실제 취향 유사도는 사용자의 활동 데이터를 활용한다.

활동 데이터는 다음 두 가지를 합친다.

```text
1. 찜한 영화의 장르
2. 리뷰를 작성한 영화의 장르
```

계산 방식은 다음과 같다.

```text
activity_score =
공통 활동 장르 수 / 전체 활동 장르 수 * 25
```

데이터가 부족한 경우에는 기본 점수를 부여한다.

| 상황                |         기본 점수 |
| ----------------- | ------------: |
| 두 사람 모두 활동 데이터 없음 |           10점 |
| 한 사람만 활동 데이터 있음   |           12점 |
| 둘 다 활동 데이터 있음     | 자카드 유사도 기반 계산 |

---

## 5-6. 최종 친구 궁합률

최종 궁합률은 다음과 같이 계산된다.

```text
compatibility =
mvti_score
+ genre_score
+ activity_score
```

최대값은 100점으로 제한한다.

```text
compatibility = min(100, mvti_score + genre_score + activity_score)
```

예를 들어 친구 궁합이 47%라면 다음과 같이 해석할 수 있다.

```text
MVTI 글자 일부 일치
+ 선호 장르 일부 겹침
+ 찜/리뷰 취향 일부 겹침
= 총 47점
```

즉 47%는 단순 랜덤 값이 아니라,
MVTI 글자, 선호 장르, 실제 활동 장르가 합산된 결과다.

---

# 6. 함께 보기 좋은 영화

## 6-1. 함께 보기 좋은 영화 추천 기준

함께 보기 좋은 영화는 나와 친구의 데이터를 모두 활용한다.

후보 영화는 다음 장르 중 하나라도 포함된 영화에서 가져온다.

```text
내 MVTI 선호 장르
+ 친구 MVTI 선호 장르
+ 내가 찜/리뷰한 영화의 장르
+ 친구가 찜/리뷰한 영화의 장르
```

후보 조건은 다음과 같다.

```text
- vote_count 20 이상
- 후보 장르와 겹치는 영화
- 인기도 높은 순 + 평점 높은 순
- 최대 250개 후보
```

후보가 부족하면 전체 인기 영화로 보완한다.

```text
- vote_count 20 이상
- 인기도 높은 순 + 평점 높은 순
- 최대 120개 추가
```

---

## 6-2. 함께 보기 좋은 영화 점수 계산

함께 보기 좋은 영화는 `couple_score`를 계산해 정렬한다.

계산식은 다음과 같다.

```text
couple_score =
내 MVTI 규칙 점수 * 0.32
+ 친구 MVTI 규칙 점수 * 0.32
+ 장르 보너스
+ 평점 점수
+ 인기도 점수
+ 투표 수 점수
```

세부 기준은 다음과 같다.

| 항목            | 계산 방식                        |
| ------------- | ---------------------------- |
| 내 MVTI 규칙 점수  | 영화가 내 MVTI와 얼마나 맞는지          |
| 친구 MVTI 규칙 점수 | 영화가 친구 MVTI와 얼마나 맞는지         |
| 장르 보너스        | 두 사람의 공통 장르, 선호 장르, 활동 장르 반영 |
| 평점 점수         | 최대 20점                       |
| 인기도 점수        | 최대 10점                       |
| 투표 수 점수       | 최대 10점                       |

---

## 6-3. 장르 보너스 계산

장르 보너스는 다음 기준으로 더해진다.

| 조건                            |  보너스 |
| ----------------------------- | ---: |
| 두 사람의 공통 선호 장르와 영화 장르가 겹침     | +18점 |
| 둘 중 한 명이라도 선호하는 장르와 영화 장르가 겹침 | +10점 |
| 찜/리뷰 기반 실제 취향 장르와 영화 장르가 겹침   | +12점 |

즉 두 사람 모두 좋아할 가능성이 높은 장르일수록 점수가 높아진다.

---

## 6-4. 평점, 인기도, 투표 수 보정

함께 보기 좋은 영화는 취향만 보지 않고 영화 자체의 신뢰도도 함께 본다.

```text
rating_score = min(vote_average * 2, 20)

popularity_score = min(popularity / 50, 10)

vote_score = min(vote_count / 500, 10)
```

즉 평점이 높고, 인기도가 높고, 투표 수가 많은 영화일수록 함께 보기 좋은 영화로 올라올 가능성이 높다.

---

## 6-5. 둘 다 MVTI를 한 경우

둘 다 MVTI 검사를 한 경우에는 다음 데이터가 모두 반영된다.

```text
1. 나의 MVTI
2. 친구의 MVTI
3. 나의 MVTI 선호 장르
4. 친구의 MVTI 선호 장르
5. 두 사람의 공통 선호 장르
6. 내가 찜/리뷰한 영화 장르
7. 친구가 찜/리뷰한 영화 장르
8. 영화의 평점
9. 영화의 인기도
10. 영화의 투표 수
```

발표 설명 예시:

> 둘 다 MVTI 검사를 한 경우에는 한 사람의 취향만 반영하지 않고, 두 사람의 MVTI 선호 장르와 실제 활동 데이터인 찜/리뷰 장르를 함께 사용합니다. 이후 두 사람 모두에게 어울리는 장르일수록 보너스를 주고, 평점과 인기도, 투표 수를 함께 반영해 같이 보기 좋은 영화를 추천합니다.

---

## 6-6. 둘 다 MVTI를 하지 않았는데 함께 보기 좋은 영화가 나오는 이유

MVTI를 하지 않았더라도 함께 보기 좋은 영화가 나올 수 있다.

그 이유는 함께 보기 좋은 영화가 MVTI만 사용하는 것이 아니라, 찜/리뷰 기반 실제 취향 장르도 사용하기 때문이다.

MVTI가 없어도 사용할 수 있는 데이터는 다음과 같다.

```text
내가 찜한 영화의 장르
친구가 찜한 영화의 장르
내가 리뷰 쓴 영화의 장르
친구가 리뷰 쓴 영화의 장르
```

만약 MVTI도 없고 찜/리뷰 데이터도 없다면, 후보 장르를 만들 수 없기 때문에 전체 인기 영화로 보완한다.

```text
- vote_count 20 이상
- 인기도 높은 순
- 평점 높은 순
```

또 두 사람 모두 MVTI도 없고 활동 데이터도 없는 경우에는 궁합률 기본값이 50으로 설정된다.

```text
if not my_mvti and not target_mvti and not my_activity_genres and not target_activity_genres:
    compatibility = 50
```

하지만 화면에서는 MVTI가 없을 경우 궁합 퍼센트를 숨기거나 제한적으로 보여줄 수 있다.

발표 설명 예시:

> MVTI가 없는 친구끼리는 성향 기반 궁합률을 정확히 계산하기 어렵습니다. 하지만 함께 보기 좋은 영화는 MVTI뿐 아니라 찜한 영화와 리뷰 작성 영화의 장르도 활용하기 때문에 추천이 가능합니다. 활동 데이터도 부족한 경우에는 전체 인기·평점 영화를 보완 추천합니다.

---

# 7. 한 문장 요약

## 오늘의 추천

> 오늘의 추천은 사용자의 현재 감정을 가장 중요하게 보고, 감정 궁합 60점, MVTI 취향 30점, 평점과 대중성 10점을 반영해 AI가 후보 영화 중 가장 적합한 영화를 선택하는 방식입니다.

## 픽시에게 요청하기

> 픽시는 사용자의 자연어 문장에서 감정, 장르, 상황 키워드를 찾고, 그에 맞는 후보 영화를 만든 뒤 AI가 가장 어울리는 영화를 따뜻한 말투로 추천하는 기능입니다.

## MVTI 맞춤 추천

> MVTI 맞춤 추천은 사용자의 MVTI를 장르 취향으로 변환하고, 장르 일치도, 평점, 인기도, 투표 수, AI 매칭 점수를 합산해 궁합률을 계산합니다.

## TOP10

> TOP10은 MVTI가 있는 사용자는 개인화 Pick Score로, MVTI가 없는 사용자는 인기도, 평점, 투표 수를 기준으로 선정합니다.

## 친구 궁합

> 친구 궁합은 MVTI 글자 유사도 40점, 선호 장르 유사도 35점, 찜/리뷰 기반 실제 취향 유사도 25점을 합산해 계산합니다.

## 함께 보기 좋은 영화

> 함께 보기 좋은 영화는 두 사람의 MVTI 선호 장르와 찜/리뷰 장르를 모두 반영하고, 평점, 인기도, 투표 수까지 함께 고려해 추천합니다.

# 8. 예상 질문과 답변

## Q1. 추천이 단순 평점순인가요?

아닙니다. 평점은 보조 지표 중 하나입니다.
오늘의 추천은 감정 궁합을 가장 크게 반영하고, MVTI 맞춤 추천은 MVTI 성향과 AI 매칭 점수를 함께 사용합니다. TOP10도 MVTI가 있는 경우에는 개인화 Pick Score를 계산합니다.

---

## Q2. MVTI 검사를 하지 않으면 추천이 안 되나요?

아닙니다. MVTI가 없어도 추천은 제공됩니다.
다만 MVTI 기반 개인화 점수는 계산하지 않고, 감정, 장르, 평점, 인기도, 투표 수, 찜/리뷰 데이터를 중심으로 추천합니다.

---

## Q3. 궁합률이 왜 56%처럼 낮게 나오나요?

궁합률은 무조건 높게 보이도록 만든 점수가 아니라, 실제 계산된 개인화 점수입니다.
MVTI 장르 일치도, 평점, 인기도, 투표 수, AI 점수를 합산해 계산하며, 최소 35%, 최대 98% 범위로 제한됩니다.

또 평점순이나 인기순으로 정렬하면 궁합률이 낮은 영화가 앞에 올 수도 있습니다.

---

## Q4. TOP10은 어떻게 선정되나요?

MVTI가 있는 사용자는 `match_percent`, `ai_score`, `rule_score`, 평점, 인기도, 투표 수를 합산한 Pick Score로 선정됩니다.
MVTI가 없는 사용자는 인기도, 평점, 투표 수를 기준으로 대중적으로 검증된 영화를 선정합니다.

---

## Q5. 친구 궁합은 어떻게 계산되나요?

친구 궁합은 세 가지 기준을 합산합니다.

```text
MVTI 글자 유사도 40점
+ MVTI 선호 장르 유사도 35점
+ 찜/리뷰 기반 실제 취향 유사도 25점
= 최대 100점
```

따라서 47%나 25% 같은 값은 랜덤이 아니라, 두 사람의 MVTI와 실제 영화 활동 데이터가 얼마나 겹치는지를 계산한 결과입니다.

---

## Q6. MVTI가 없는 친구끼리도 함께 보기 좋은 영화가 나오는 이유는 무엇인가요?

함께 보기 좋은 영화는 MVTI만 사용하는 것이 아니라, 찜한 영화와 리뷰 작성 영화의 장르도 사용합니다.
그래서 MVTI가 없어도 활동 데이터가 있으면 그 장르를 바탕으로 추천할 수 있고, 활동 데이터도 부족하면 전체 인기·평점 영화로 보완 추천합니다.

---

# 9. 최종 발표 멘트 예시

저희 Pick & Go 추천 시스템은 사용자가 가진 데이터의 양에 따라 추천 기준을 다르게 적용합니다.

사용자가 MVTI 검사를 했다면 MVTI 성향을 장르 취향으로 변환해 개인화 추천을 제공하고, MVTI가 없다면 감정, 장르, 평점, 인기도, 투표 수 같은 기본 영화 데이터를 활용해 추천이 끊기지 않도록 설계했습니다.

오늘의 추천은 사용자의 현재 감정을 가장 크게 반영합니다. 감정 궁합 60점, MVTI 취향 30점, 평점과 대중성 10점을 기준으로 후보 영화를 만들고, AI가 그중 가장 적합한 영화를 선택합니다.

MVTI 맞춤 추천은 장르 일치도, 평점, 인기도, 투표 수, AI 매칭 점수를 합산해 궁합률을 계산합니다. TOP10은 MVTI가 있는 경우 개인화 Pick Score를 사용하고, MVTI가 없는 경우에는 인기도와 평점, 투표 수를 기준으로 선정합니다.

친구 궁합은 MVTI 글자 유사도, 선호 장르 유사도, 찜/리뷰 기반 실제 취향 유사도를 합산해 계산합니다. 함께 보기 좋은 영화는 두 사람의 MVTI와 실제 활동 데이터를 모두 반영해, 한 사람에게만 맞는 영화가 아니라 둘이 같이 보기 좋은 영화를 추천하도록 만들었습니다.

즉 Pick & Go는 단순한 평점순 추천이 아니라, 감정 기반 추천, MVTI 기반 개인화 추천, AI 큐레이션, 친구 취향 분석을 결합한 영화 추천 서비스입니다.
